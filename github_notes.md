# GitHub — заметки

## Команды
- `git remote add origin <URL>` — подключить удаленный репозиторий
- `git push -u origin main` — первый push
- `git push` — обычный push
- `git pull` — скачать и слить изменения
- `git fetch` — только скачать

## Аутентификация
- Пароль заменен на Personal Access Token (PAT)
- Токен создается в Settings → Developer settings → Personal access tokens
